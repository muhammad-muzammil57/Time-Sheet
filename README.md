# 📝 TimeSheet Pro

A clean, modern, and fully interactive **daily task & time-tracking web
application** built using **HTML, CSS, JavaScript, and Chart.js**. This
project allows users to **track activities, manage priorities, record
working hours, analyze productivity**, and visualize completed vs
remaining tasks using a dynamic chart.

## 📌 About the Project

**TimeSheet Pro** is a lightweight, browser-based productivity tool
designed to help users:

-   Record daily work tasks\
-   Track start and end times\
-   Mark tasks as done or pending\
-   Highlight important tasks using priority badges\
-   Edit tasks anytime\
-   Filter tasks by date\
-   Search tasks by name\
-   Visualize progress with a beautiful pie chart\
-   Switch between **Dark Mode / Light Mode**

All data is stored in **LocalStorage**, so your tasks remain saved even
after closing the browser.

## 🎯 Purpose of the Project

The goal of building **TimeSheet Pro** was to create:

-   A simple alternative to complex task-tracking apps\
-   A daily productivity tool for students, freelancers, and developers\
-   A fully client-side tool without backend dependencies\
-   A clean UI with neon theme & smooth UX\
-   A practical example for beginners learning JavaScript CRUD
    operations

## 🛠️ Technologies Used

  Technology             Purpose
  ---------------------- -----------------------------------------
  **HTML5**              Structure of the app
  **CSS3**               Styling, dark/light theme, neon effects
  **JavaScript (ES6)**   Core logic, CRUD operations, filtering
  **Chart.js**           Rendering task completion pie chart
  **LocalStorage API**   Saving and loading tasks
